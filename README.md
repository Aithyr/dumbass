# dumbass

the cave, as a website.

```
index.html        the whole thing
assets/style.css  the paint
assets/app.js     the typing, the reveal, the clock
```

No build step, no dependencies, no framework. Open `index.html` and it works.

## deploy

GitHub Pages → *Settings → Pages* → source **Deploy from a branch** →
branch `main`, folder `/ (root)`.

Then it lives at <https://aithyr.github.io/dumbass/>.

## edit

- phrases for the typing line: `PHRASES` in `assets/app.js`
- colours: `:root` in `assets/style.css`
- copy: straight out of `index.html`
